# 冰冻关卡（CHALLENGE_ICE）沙盒背包

给隐藏挑战中的“冰冻关卡”(`GAMEMODE_CHALLENGE_ICE`) 增加的排演/录制功能：
关卡内即可自选任意植物与任意常规僵尸，放到草地上任意位置，用于布景、测试与录制。

## 使用方式

1. 从隐藏挑战列表进入“冰冻关卡”（显示名为 `[ICE_LEVEL]` 的隐藏小游戏）。
2. 进入后上方工具条出现 **背包** 按钮（也可按 `B` 键）。
3. 打开背包后可切换四个分页：**植物 / 僵尸 / 旅行 / 工具**：
   - 植物页：41 种适合草地作战的常规植物（不含只适用于泳池/屋顶/加农炮等特殊种子，
     也不含咖啡豆——沙盒里蘑菇会自动唤醒，咖啡豆无意义）。
   - 僵尸页：19 种常规敌方僵尸（普通、路障、撑杆、铁桶、读报、铁门、橄榄球、
     舞王、小丑、气球、矿工、跳跳、梯子、投石车、巨人、小鬼、冰车、红眼巨人、旗帜）。
   - 旅行页：旅行模式（`CHALLENGE_TRAVEL_*`）专属植物，冰关沙盒内也能用：
     **巨大坚果**（红卡，占两格：点击的格子为左锚，自动覆盖右邻一格）与
     **大喷菇群**（紫卡，无需先种大喷菇，可直接成株）。
   - 工具页：橡皮擦——删除任何植物/僵尸单位。
4. 点击任意一张卡即“拿到手上”，背包自动关闭；
   之后 **左键点击任意草地格子**：
   - 植物 → 无视地形/升级/植物限制直接种下（同格已有植物会被替换）。
   - 僵尸 → 从该格子原地出现并往左进攻（可多个重叠）。
   - 橡皮擦 → 删除该格植物与该行路过该格的僵尸。
5. 想连续摆放同一单位就连续点击多个格子；**右键 / 点草地外 / 按 Esc** 均可把卡牌放下。

## 沙盒规则

- 无限阳光（不消耗），天降阳光关闭；没有关卡波次、不生成自然僵尸。
- **不判定输赢**：僵尸走到房子（场地最左端）会安静退场；
  该模式也不再有原版 3000 帧后的“结束音效彩蛋”。
- 无小推车。
- 蘑菇类（小喷菇/阳光菇/大喷菇/魅惑/胆小/寒冰/毁灭/磁力/忧郁等）在白天草坪
  上原本会睡着，沙盒放置时会自动唤醒，便于直接当夜战使用。
- 铲子依旧可用：挖除植物。

## 按键

| 按键 | 功能 |
| --- | --- |
| 背包按钮 / `B` | 开关背包 |
| 左键 | 选卡 / 放置 |
| 右键 / 空地点击 / `Esc` | 放下手里卡牌 |
| `Esc` | 依次：关背包 → 放下卡牌 → 弹出暂停菜单 |

## 实现位置

- `src/Lawn/Board.h` / `Board.cpp`：沙盒状态与 UI（`IsIceSandboxLevel`、
  `DrawIceSandboxUI`、`IceSandboxHandleMouseDown`、`IceSandboxBagDraw`、
  `IceSandboxPlaceArmedAt`、植物/僵尸/旅行卡表 `gIceSandboxPlantSeeds` /
  `gIceSandboxZombieTypes` / `gIceSandboxTravelSeeds` 等），并接入
  `Board::Draw / MouseDown / KeyDown`。其中旅行页的巨大坚果按“两格宽、
  点击格为左锚”特判落子。
- `src/Lawn/Zombie.cpp`：`CheckForBoardEdge` 中冰冻沙盒关僵尸到边不判负。
- `src/Lawn/Challenge.cpp`：移除冰冻关 3000 帧彩蛋音效。
- `src/Lawn/Board.cpp`：`InitLawnMowers` 冰冻沙盒关不创建小推车；
  `InitLevel` 冰冻关分支不再发放固定卡牌，改为沙盒初始化。
