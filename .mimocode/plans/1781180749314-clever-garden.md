# 杨桃子弹追踪效果实现计划

## 需求
- 5颗杨桃子弹先按原轨迹飞行1格（80像素），然后追踪离房子最近的僵尸
- 矿工僵尸也作为追踪目标，但只分配1颗子弹（向左飞的那颗）来打矿工
- 目标僵尸被消灭后，子弹继续追踪下一个最近的僵尸（同帧切换，无延迟）
- 全部5颗子弹都添加追踪效果

## 设计思路

### 核心逻辑
在 `MOTION_STAR` 的更新代码中，当 `mProjectileAge >= 24`（约80像素行程）时：
1. 查找离房子最近的僵尸
2. 将其ID存入 `mTargetZombieID`
3. 后续帧使用追踪逻辑（参考 `MOTION_HOMING` 的实现）

### 矿工僵尸分配
- 向左飞的子弹（mVelX < 0）可以追踪矿工僵尸
- 其余4颗子弹不追踪矿工，只追踪普通僵尸
- 这样自然分配了1颗子弹来处理矿工威胁

### 为什么不需要新字段
- `mTargetZombieID` 已有序列化支持，默认值为 `ZOMBIEID_NULL`
- 用 `mTargetZombieID != ZOMBIEID_NULL` 判断是否进入追踪阶段
- 不破坏存档兼容性

改为：
```cpp
else if (mMotionType == ProjectileMotion::MOTION_STAR)
{
    if (mProjectileAge >= 24)
    {
        bool aNeedNewTarget = (mTargetZombieID == ZombieID::ZOMBIEID_NULL);
        if (!aNeedNewTarget)
        {
            Zombie* aCurZombie = mBoard->ZombieTryToGet(mTargetZombieID);
            if (!aCurZombie || !aCurZombie->EffectedByDamage(static_cast<unsigned int>(mDamageRangeFlags)))
            {
                mTargetZombieID = ZombieID::ZOMBIEID_NULL;
                aNeedNewTarget = true;
            }
        }
        if (aNeedNewTarget)
        {
            bool aCanTargetDigger = (mVelX < 0.0f);
            Zombie* aBestZombie = nullptr;
            int aMinX = INT32_MAX;
            Zombie* aZombie = nullptr;
            while (mBoard->IterateZombies(aZombie))
            {
                if (!aCanTargetDigger && aZombie->mZombieType == ZombieType::ZOMBIE_DIGGER)
                    continue;
                if (!aZombie->EffectedByDamage(static_cast<unsigned int>(mDamageRangeFlags)))
                    continue;
                if (aZombie->mX < aMinX)
                {
                    aMinX = aZombie->mX;
                    aBestZombie = aZombie;
                }
            }
            if (aBestZombie)
            {
                mTargetZombieID = mBoard->ZombieGetID(aBestZombie);
            }
        }
    }

    if (mTargetZombieID != ZombieID::ZOMBIEID_NULL)
    {
        Zombie* aZombie = mBoard->ZombieTryToGet(mTargetZombieID);
        if (aZombie && aZombie->EffectedByDamage(static_cast<unsigned int>(mDamageRangeFlags)))
        {
            Rect aZombieRect = aZombie->GetZombieRect();
            SexyVector2 aTargetCenter(aZombie->ZombieTargetLeadX(0.0f), aZombieRect.mY + aZombieRect.mHeight / 2);
            SexyVector2 aProjectileCenter(mPosX + mWidth / 2, mPosY + mHeight / 2);
            SexyVector2 aToTarget = (aTargetCenter - aProjectileCenter).Normalize();
            SexyVector2 aMotion(mVelX, mVelY);
            aMotion += aToTarget * (0.001f * mProjectileAge);
            aMotion = aMotion.Normalize();
            aMotion *= 3.33f;
            mVelX = aMotion.x;
            mVelY = aMotion.y;
            mRotation = -atan2(mVelY, mVelX);
        }
    }

    mPosY += mVelY;
    mPosX += mVelX;
    mShadowY += mVelY;
    if (mVelY != 0.0f || mTargetZombieID != ZombieID::ZOMBIEID_NULL)
    {
        mRow = mBoard->PixelToGridYKeepOnBoard(mPosX, mPosY);
    }
}
```

#### 修改2：`CheckForCollision()` 中添加追踪碰撞检测（行289-298之后）

在 `PROJECTILE_STAR` 的越界死亡检查之后、阴影过滤之前，添加追踪碰撞逻辑：

```cpp
if (mProjectileType == ProjectileType::PROJECTILE_STAR && mTargetZombieID != ZombieID::ZOMBIEID_NULL)
{
    Zombie* aZombie = mBoard->ZombieTryToGet(mTargetZombieID);
    if (aZombie && aZombie->EffectedByDamage(static_cast<unsigned int>(mDamageRangeFlags)))
    {
        Rect aProjectileRect = GetProjectileRect();
        Rect aZombieRect = aZombie->GetZombieRect();
        if (GetRectOverlap(aProjectileRect, aZombieRect) >= 0 && mPosY > aZombieRect.mY && mPosY < aZombieRect.mY + aZombieRect.mHeight)
        {
            DoImpact(aZombie);
        }
    }
    return;
}
```

## 关键参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| 追踪触发帧数 | 24 | 24帧 × 3.33像素/帧 ≈ 80像素（1格） |
| 追踪速度 | 3.33 | 保持原速不变 |
| 追踪转向力 | 0.001f × mProjectileAge | 参考Cattail，随时间增强 |
| 目标选择 | 离房子最近 | mX最小的僵尸 |
| 矿工分配 | 仅向左飞的子弹 | mVelX < 0 的子弹可以追踪矿工，其余4颗不追踪矿工 |

## 验证方法

1. **编译测试**：确保代码无编译错误
2. **功能测试**：
   - 种植杨桃，观察子弹先直飞约1格后开始追踪
   - 确认追踪目标是离房子最近的僵尸
   - 确认5个方向的子弹都能追踪
   - 确认只有向左飞的子弹会追踪矿工僵尸，其余4颗不追踪矿工
   - 确认追踪子弹能穿透盾牌（如铁栅门僵尸的盾牌）
3. **存档测试**：
   - 保存游戏，加载后确认追踪中的子弹状态正确
   - 不会因为新字段导致旧存档加载失败
4. **边界测试**：
   - 无僵尸时子弹保持原轨迹飞行
   - 目标僵尸死亡后子弹继续追踪下一个最近的僵尸（同帧切换）
   - 所有僵尸死亡后子弹保持最后方向飞行
