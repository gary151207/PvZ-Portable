# 斗蛐蛐 (Cricket Fight) 新小游戏设计

**日期:** 2026-08-17
**状态:** 待实现
**类型:** 新 GameMode（小游戏挑战）

## 目标

新增一个小游戏挑战「斗蛐蛐」：5 个随机植物 vs 6 个随机僵尸，纯自动战斗，玩家全程观战。每次进入完全随机重掷，胜负难料 —— 呼应斗蛐蛐的观赏性与不确定性。

## 核心玩法

- **地图**：黑夜（`BACKGROUND_2_NIGHT`）
- **单线对决**：双方全部位于第 3 行（网格行索引 2，中间格线）
  - 我方：5 个随机植物，固定摆在第 1-5 列（网格列索引 0-4），每列 1 个
  - 敌方：6 个随机僵尸，从右侧进入，沿第 3 行走来
- **纯自动战斗**：
  - 植物自动攻击，不依赖阳光经济
  - 无种子栏、无铲子、无手动操作
  - 跳过选卡界面，进关自动开战
- **完全随机**：每次进入关卡重新掷全部随机量
  - 植物种类：随机池 = 技术安全的全量池（见下方排除清单）
  - 植物顺序：5 个植物在 5 个格位间随机排列
  - 僵尸种类：随机池 = 技术安全的全量池（见下方排除清单）

## 胜负规则

- **胜利**：6 只僵尸全部死亡
- **失败**（斗蛐蛐式决斗语义）：5 个植物全部死亡（且场上仍有僵尸存活）或 任意僵尸进入房屋
- **单场制**：结束后返回小游戏列表；再次进入 = 全新随机对战

## 随机池排除清单

排除项为**技术上无法独立运作 / 会导致软锁或异常表现**的种类（非平衡保底）。平衡风险（抽到向日葵白给、抽到伽刚特尔打不过）全部保留，这是用户选择的「全量随机」设计意图。

### 植物池（SEED_PEASHOOTER(0) 至 SEED_IMITATER(48)，排除以下 7 种）

| 排除 | 原因 |
|------|------|
| `SEED_LILYPAD` | 池专属，陆地上表现异常 |
| `SEED_TANGLEKELP` | 池专属，陆地上无效果 |
| `SEED_CATTAIL` | 需要睡莲支撑 |
| `SEED_PUMPKINSHELL` | 包裹对象为空，无意义 |
| `SEED_FLOWERPOT` | 无意义 |
| `SEED_COBCANNON` | 需要双格玉米加农炮配对，单独放置可能异常 |
| `SEED_IMITATER` | 占位符，不是真实植物 |

排除后池内 42 种，含向日葵/坚果/海金花等无攻击植物（保留风险）与樱桃/窝瓜/毁灭菇等自动引爆植物（PvZ1 中种植后自动引爆，无需点击，自动战斗可用）。

### 僵尸池（ZOMBIE_NORMAL(0) 至 ZOMBIE_REDEYE_GARGANTUAR(32)，排除以下 13 种）

| 排除 | 原因 |
|------|------|
| `ZOMBIE_BACKUP_DANCER` | 仅能由舞者召唤，独立生成可能异常 |
| `ZOMBIE_DUCKY_TUBE` / `ZOMBIE_SNORKEL` / `ZOMBIE_DOLPHIN_RIDER` | 池专属僵尸 |
| `ZOMBIE_BOBSLED` | 仅出现在雪橇关卡编组 |
| `ZOMBIE_YETI` | 受击后逃出关卡，导致无法判定全灭 |
| `ZOMBIE_BOSS` | 最终 BOSS 特殊行为 |
| `ZOMBIE_PEA_HEAD` ~ `ZOMBIE_TALLNUT_HEAD` | 益智模式（I, Zombie）头部变体 |

排除后池内 20 种，含伽刚特尔/白眼伽刚特尔/气球僵尸（无仙人掌+三叶草时气球无敌→必输，保留此风险）/玩偶匣/矿工等。

### Board 改动细节

1. **背景**：`PickBackground()` 中为该模式指定 `BACKGROUND_2_NIGHT`
2. **初始阳光**：无阳光经济，`mSunMoney = 0`（与 Beghouled 等模式一致的处理方式）
3. **初始布阵**：`InitLevel()` 或 `StartLevel()` 时，在 (col 0-4, row 2) 随机摆放 5 个随机植物（通过 `AddPlant`，按随机顺序排列 5 个随机 SeedType）
4. **出怪**：定制 `InitZombieWaves()` —— 一波直接出 6 只随机僵尸，全部走第 3 行（固定出怪路径，绕过点数预算系统）；开局即刷出（`mZombieCountDown` 极短或直接生成）
5. **UI 隐藏**：隐藏种子栏（SeedBank）、铲子按钮、阳光计数等玩家交互元素；纯观战
6. **胜负判定**：
   - 胜利：复用现有波次结算（全部波刷完且全灭 → 关卡完成）
   - 失败：僵尸进家（复用现有失败检测）；植物全灭且场上仍有僵尸 → 立即判负（斗蛐蛐决斗语义）

## 边界情况

- 抽到纯辅助植物（5 个向日葵）→ 必然失败，这是"完全随机"的设计意图，不做保底
- 抽到伽刚特尔等强僵尸 → 可能无法战胜，同上
- 夜间无睡眠机制（PvZ1 原版行为），日间植物在黑夜正常工作，无需额外处理
- 大蒜将僵尸引向相邻行（1/3 行，无植物驻守）→ 该僵尸直冲房屋 = 失败，保留此风险
- 气球僵尸在无仙人掌/三叶草时无敌 → 必输，保留此风险
- 双失败同帧（最后一只僵尸与最后一株植物同时死亡）：先判胜利（僵尸全灭优先）

## 不做的事（YAGNI）

- 不做连胜/锦标赛模式（用户选择单场制）
- 不做手动干预（铲子、重新摆放、暂停操作）
- 不做难度分级或平衡保底
- 不新增美术资源（复用现有植物/僵尸精灵与黑夜背景）

## 验证

无自动化测试（项目无测试套件）。验证方式：
- 构建通过（cmake + Ninja Release）
- 手动游玩：从小游戏页进入「斗蛐蛐」→ 确认黑夜地图、5 植物摆在第 3 行 1-5 列、6 僵尸沿第 3 行进攻、无种子栏/铲子/阳光 UI
- 多次进入确认每次随机量不同
- 分别验证胜利（僵尸全灭）与失败（植物全灭 / 僵尸进家）两条结算路径
