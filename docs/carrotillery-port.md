# 胡萝卜导弹车移植记录

胡萝卜导弹车固定为《植物大战僵尸 2》国服四阶，只出现在斗蛐蛐 2 第二选卡页、莲小蓬之后。不接入其它阶数、种植觉醒、能量豆、能量豆地块和落地大导弹。

## 数值与战斗

| 项目 | 实现 |
| --- | --- |
| 阳光 / 卡片冷却 / 生命 | 450 / 10 秒 / 750 |
| 单发伤害 | 直击 1000；落点单格内其它僵尸各 100 |
| 一次攻击 | 锁定同行一只僵尸，约 3 秒内依 PAM 的四个 `use_action` 依次发弹 |
| 装填 | 第四发出膛后 1100 个逻辑刻（11 秒） |

四发只记录一个目标 ID。每次出弹前更新该目标的位置；目标死亡后仍向最后记录的位置发射余弹。普通飞弹只会直接撞击被锁定的僵尸，落点同格其它僵尸只受溅射。普通攻击由 `Plant` 和 `Projectile` 的枚举分支实现，未添加植物子类，也未加入 `IsPultPlant`。

植物的连射进度存入可选 `.v4` TLV 字段 `102`；装填计时、目标 ID 与最后位置沿用既有植物字段。飞行中弹丸的目标 ID 沿用既有弹丸字段。旧存档缺少字段 `102` 时连射进度为零。

## 资源

运行 `python3 scripts/gen-carrotillery-reanim.py` 从用户提供的 `carrotlauncher` PAM 与 PNG 生成本体、普通飞弹和普通命中动画。`--check` 校验源 PAM 的 SHA-256、动画标签、四个普通攻击动作点、输出文件和图片引用。脚本只读取普通攻击所需的 `carrotlauncher` 素材，不读取 `carrotmissile` 图集，也不输出装扮或能量豆动画。

生成的三份 `.reanim` 与 82 张 PNG 位于 `res/main/reanim/`，由现有资源管线打包。
