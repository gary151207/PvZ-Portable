# 莲小蓬移植记录

莲小蓬在本项目中固定为《植物大战僵尸 2》国服四阶。它仅出现在斗蛐蛐 2 的第二选卡页，紧跟椰子加农炮；没有阶数切换、能量豆或能量豆地块机制。

## 数值与战斗

| 项目 | 实现 |
| --- | --- |
| 阳光 / 卡片冷却 | 200 / 5 秒 |
| 生命 / 每发伤害 | 750 / 300 |
| 攻击周期 | 2.9–3.1 秒，单次攻击只发一枚 |
| 陆地 | 抛射莲子，单体命中 |
| 水面 | 无需睡莲种植，直线鱼雷；碰撞点左右各 80 像素、同一行受伤 |
| 四阶继承能力 | 每枚命中弹丸独立掷一次 30% 眩晕；成功后其有效伤害目标停滞 200 个逻辑刻（2 秒） |

僵尸眩晕计时器单独保存在 `.v4` 僵尸 TLV 字段 `4`；旧存档没有该字段时计时器为零。植物和弹丸沿用现有 `Plant`、`Projectile`、`Zombie` 的枚举分支，没有新增实体子类。

## 资源

`python3 scripts/gen-lotus-pod-reanim.py` 从用户提供的 `lotusshower` 目录转换常态本体、普通莲子、普通鱼雷、命中和眩晕视觉。`--check` 核对输出与源素材一致，同时校验 PAM JSON 的 SHA-256、动画标签和普通攻击动作点。名称中带 `PLANTFOOD` 的两份弹丸 PAM 只取各自的 `normal` 片段，不生成能量豆动作。

输出的五份 `.reanim` 与 PNG 放在 `res/main/reanim/`，打包时由现有资源管线收入 `main.pak`。
